Live engine notes

The browser does not scrape NSE directly. Your pasted URL is sent to the local Node.js backend. The backend opens that NSE page to establish session cookies, then requests the option-chain JSON and returns it to the dashboard.

Polling every second can trigger NSE rate limits or temporary blocking. This build does exactly 1-second refresh as requested, but 3–5 seconds is safer for continuous use.

Educational analysis only. OI interpretation is probabilistic and should not be used as the sole basis for a trade.
